# Vipin Consultancy Portfolio

A high-end, professional, and bilingual (English/Hindi) portfolio website for **Vipin Consultancy**, a premier Property E-Registry Service Provider based in Sagar, Madhya Pradesh.

![Project Preview](https://vipin-consultancy.vercel.app/logo.png)

## 🚀 Features

- **Bilingual Support (i18n)**: Seamless English and Hindi language toggle with full translation coverage.
- **Mobile Optimized**: Fully responsive design with a custom mobile-first navigation and adaptive layouts.
- **Dynamic Image Album**: A smooth, auto-playing gallery featuring professional architecture and office photography.
- **Modern UI/UX**: Built with a deep Navy & Red brand palette, glassmorphism effects, and smooth micro-animations.
- **Lead Generation**: Interactive "Request Callback" form with loading and success states.
- **WhatsApp Integration**: Floating contact widget for instant client engagement.
- **SEO Optimized**: Semantic HTML5 structure and optimized metadata for better search rankings.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 📂 Project Structure

```text
├── app/               # Next.js App Router (Layouts, Pages, Globals)
├── components/        # Reusable UI Components (Hero, Navbar, Footer, etc.)
├── context/           # Global State (LanguageContext)
├── lib/               # Utility functions and Translations
├── public/            # Static assets (Images, Logo, Icons)
└── tailwind.config.ts # Tailwind CSS configuration
```

## ⚙️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/ayushpatel996/e-registry.git
cd vipin-consultancy
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 4. Build for production
```bash
npm run build
```
